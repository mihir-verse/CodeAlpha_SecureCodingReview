# CodeAlpha Secure Coding Review

## About the Project
This project demonstrates how to identify and improve
common security vulnerabilities in Python and JavaScript.

## Languages Used
- Python
- JavaScript

## Python Security Review
- Identifies unsafe SQL query construction.
- Demonstrates parameterized SQL queries.
- Includes a security report.

## JavaScript Security Review
- Identifies unsafe DOM manipulation using innerHTML.
- Demonstrates safer text output using textContent.
- Includes a security report.

## Project Structure
- Python/
  - vulnerable_code.py
  - secure_code.py
  - security_report.md
- JavaScript/
  - vulnerable_code.js
  - secure_code.js
  - security_report.md

## Testing
The Python examples were executed locally.
The JavaScript examples were reviewed by comparing
vulnerable and secure DOM manipulation patterns.
